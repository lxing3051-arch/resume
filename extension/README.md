# 秋招助手 - Boss 直聘浏览器插件

零成本，一键抓取 Boss 直聘岗位 JD 并导入秋招助手。

## 安装（开发者模式，免费）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions` 或 `edge://extensions`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本项目的 `extension` 文件夹
5. **重要**：若之前已加载过，点击插件卡片上的 **刷新 ↻** 更新到最新版

## 使用

1. **登录** Boss 直聘（未登录可能抓不到完整 JD）
2. 打开某个 **岗位详情页**（URL 含 `job_detail`，不是搜索列表）
3. **刷新该页面一次**（F5）
4. 点击浏览器工具栏的 **秋招助手** 图标
5. 选择：
   - **打开秋招助手并导入**
   - **复制到剪贴板** → 在网站「添加公司」点「从剪贴板导入」

## 配置秋招助手地址

插件弹窗 → **设置秋招助手地址**

| 场景 | 地址 |
|------|------|
| 本地开发 | `http://localhost:5173` |
| GitHub Pages | `https://你的用户名.github.io/仓库名` |
| Vercel / Netlify | `https://你的项目.vercel.app` |

## 抓取失败？按此排查

| 现象 | 解决办法 |
|------|----------|
| 「请先打开岗位详情页」 | 点进具体岗位，不要停在搜索列表 |
| 「需要登录」 | 在 zhipin.com 登录后 **F5 刷新** |
| 「抓取失败 / 无法读取页面」 | 1. 扩展管理页 **刷新插件** 2. Boss 页面 **F5** 3. 再点插件 |
| 公司/岗位为空但 JD 有内容 | 正常，导入后在秋招助手里手动改公司名 |
| 仍失败 | 在岗位页 **Ctrl+A 复制** 全文，到秋招助手 **粘贴 JD 文本** |
